# Prompt: Automação N8N — Chamados do Microsoft Teams no Todoist

Prompt para gerar, com um assistente de IA, uma automação no N8N que registra automaticamente no Todoist os chamados recebidos pelo Microsoft Teams.

## Prompt

```
Atue como um especialista em N8N.

Crie uma automação para registrar automaticamente no Todoist os chamados recebidos pelo Microsoft Teams.

Público:
Equipe de vendas

Ferramentas envolvidas:
Microsoft Teams, Todoist

Fluxo:
1. Receber os chamados enviados pelo Microsoft Teams.
2. Abrir um ticket (tarefa) no Todoist com os dados do chamado.
3. Responder no Microsoft Teams informando que o chamado foi aberto.

Regras:
- Ignorar registros sem e-mail válido.

Explique quais nós do N8N devem ser utilizados e a lógica de funcionamento do workflow.
```

## Resumo

| Item | Descrição |
|---|---|
| **Público** | Equipe de vendas |
| **Ferramentas** | Microsoft Teams, Todoist, N8N |
| **Resultado esperado** | Chamados salvos como tarefas no Todoist |
| **Regra principal** | Ignorar registros sem e-mail válido |
